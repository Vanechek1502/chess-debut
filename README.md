# ♟️ Chess Debut

**Веб-приложение для тренировки и изучения шахматных дебютов.**

## 📖 О проекте
Этот сайт помогает шахматистам быстро и интерактивно учить дебютные линии. Идеально подходит для ежедневной разминки перед партиями.

---

## 🚀 Как запустить сайт на своем компьютере

Если вы хотите запустить этот сайт у себя, следуйте этой простой инструкции:

### 1. Установите программу Node.js
Сайт работает на технологии, которой нужен «движок».
1. Перейдите на официальный сайт [nodejs.org](https://nodejs.org/).
2. Скачайте версию **LTS** (она отмечена как *«Рекомендуется для большинства»* / *Recommended For Most Users*).
3. Установите её (просто нажимайте **Next** во всех окнах).

### 2. Скачайте проект
1. Нажмите на зеленую кнопку **`<> Code`** вверху этой страницы.
2. Выберите **Download ZIP**.
3. Распакуйте скачанный архив в любую удобную папку на компьютере.

### 3. Запустите сайт
1. Откройте распакованную папку.
2. Нажмите правой кнопкой мыши в пустом месте папки и выберите **«Открыть в терминале»** (или *Open in Terminal*).
3. В открывшемся окне введите по очереди две команды, нажимая **Enter** после каждой:

```bash
npm install
```
*(подождите минутку, пока программа скачает всё необходимое)*

```bash
npm run dev
```

4. После ввода второй команды в терминале появится локальная ссылка (обычно она выглядит так: `http://localhost:5173`).
5. Удерживая клавишу **Ctrl**, нажмите на эту ссылку мышкой — сайт откроется в вашем браузере!

---

## ❓ Возникли вопросы?

> **Совет:** Если при запуске что-то пошло не так, проверьте, правильно ли установился Node.js. Введите в терминале команду:
> ```bash
> node -v
> ```
> Если в ответ вы видите номер версии (например, `v22.x.x`) — значит, программа установлена корректно!
